# PRKSH — Portfolio

A responsive, minimal portfolio website for Udhanshetti Prakash.

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Create a public repository named `prksh-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be published at `https://YOUR-USERNAME.github.io/prksh-portfolio/`.

For the account-level address `https://YOUR-USERNAME.github.io/`, name the repository exactly `YOUR-USERNAME.github.io`.

## Personalize before publishing
- Update the GitHub profile URL in `index.html` if your username changes.
- Confirm that the `FaramaAI` and `Easy-Track` repository URLs match your actual repositories.
- Add a LinkedIn URL or professional email when you are ready.
